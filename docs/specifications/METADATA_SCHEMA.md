---

# 1. Purpose

This specification defines the canonical metadata model used to describe engineering evidence within the Open Engineering Platform.

Metadata provides the descriptive information required for discovery, indexing, traceability, semantic analysis, lifecycle management, and engineering reasoning.

Metadata supplements engineering evidence but never replaces or modifies it.

---

# 2. Design Principles

Engineering metadata shall be:

- Structured
- Extensible
- Deterministic
- Searchable
- Machine-readable
- Human-readable
- Versioned
- Traceable

Metadata shall always preserve the distinction between:

- Captured Metadata
- Derived Metadata
- Human Metadata
- AI Metadata

---

# 3. Metadata Architecture

Engineering metadata consists of multiple layers.

```text
Metadata

├── Identity
├── Source Metadata
├── Document Metadata
├── Engineering Metadata
├── Classification
├── Technical Metadata
├── Extraction Metadata
├── AI Metadata
├── Search Metadata
├── Lifecycle Metadata
└── Audit Metadata
```

---

# 4. Identity Metadata

Required

| Field | Type |
|---------|------|
| metadata_id | UUID |
| schema_version | String |
| created_at | Timestamp |
| created_by | User/System |

Identity metadata never changes.

---

# 5. Source Metadata

Captured during acquisition.

Fields

- Organization
- Source URL
- Endpoint
- Service
- Acquisition Date
- Acquisition Method
- Original Filename
- MIME Type
- File Size

This information reflects the original source.

Fields

- Subtitle
- Authors
- Publisher
- Publication Date
- Revision
- Language
- Edition
- Copyright
- ISBN
- DOI
- Document Number

Examples

- Formula Count

# 9. Classification Metadata

Supports organization and retrieval.

Fields

- Knowledge Domain
- Engineering Domain
- Tags
- Keywords
- Topics
- Object Categories
- Security Classification
- Confidentiality

Multiple classifications may exist simultaneously.

---

# 10. Extraction Metadata

Generated by the Universal Ingestion Framework.

Examples

- OCR Completed
- OCR Confidence
- Layout Analysis
- Tables Extracted
- Images Extracted
- Text Blocks
- Entity Count
- Relationship Count
- Chunk Count

Extraction metadata is reproducible.

---

# 11. AI Metadata

Generated by AI-assisted processing.

Examples

- Summary
- Suggested Categories
- Suggested Relationships
- Suggested Engineering Objects
- Confidence Scores
- Embedding Model
- Embedding Version
- Token Count

AI metadata is advisory.

It never replaces human review.

---

# 12. Search Metadata

Optimized for retrieval.

Examples

- Full Text Index
- Semantic Index
- Vector Embeddings
- Keywords
- Synonyms
- Search Boosts
- Language Index

Search metadata may be regenerated.

---

# 13. Lifecycle Metadata

Tracks metadata evolution.

Fields

- Created
- Modified
- Reviewed
- Approved
- Archived

Metadata history is preserved.

---

# 14. Audit Metadata

Records metadata activity.

Events

- Created
- Updated
- Extracted
- AI Generated
- Human Corrected
- Reviewed
- Published

Audit history is append-only.

---

# 15. Relationships

Metadata may reference

- Acquisition Records
- Vault Objects
- Organizations
- Engineering Knowledge Objects
- Projects
- Standards
- Components
- Diagrams
- Engineering Packages

Relationships are immutable.

# 19. Summary

The Metadata Schema defines the standardized descriptive model for engineering evidence within the Open Engineering Platform.

Metadata enables efficient discovery, semantic understanding, engineering traceability, and AI-assisted processing while preserving the integrity and provenance of the original engineering evidence.
