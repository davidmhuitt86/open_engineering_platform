# SDD-028

# Symbol Definition Specification

Status: Frozen

Version: 1.0

---

# Purpose

Defines every Engineering Symbol.

Symbols are data.

Never code.

---

# Symbol Definition

Every symbol shall define:

Identifier

Name

Category

Description

Aliases

Standards

Geometry

Ports

Rendering Metadata

Validation Rules

# Ports

Every port defines:

Identifier

Display Name

Connection Type

Direction

# Geometry

SVG

---

# Rendering

Rendering Metadata includes:

Default Color

Stroke Width

Fill

Layer

Snap Points

Connection Anchors

---

# Validation

Validation Rules define:

Required Ports

Allowed Connections

Orientation

Required Metadata

---

# Unknown Symbols

Unknown Symbols remain valid.

Unknown Symbols preserve evidence.

Unknown Symbols may later be classified.

---

# Architecture Rules

Symbols contain no Engineering Knowledge.

Symbols define appearance only.

Engineering Knowledge exists in the Engineering Graph.
