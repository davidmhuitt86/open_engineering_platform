# 1. Purpose

This document defines the iconography and visual symbol system used throughout the OEP Instruments platform.

Icons communicate engineering information quickly and consistently.

They shall supplement engineering data, never replace it.

---

# 2. Philosophy

Professional engineers should recognize an instrument's state at a glance.

Icons exist to reduce cognitive load.

Every icon shall have one meaning.

Every meaning shall have one icon.

Icons shall never be decorative.

---

The icon system shall be:

Professional

Consistent

Minimal

Recognizable

Scalable

Accessible

Platform Independent

# 5. Design Language

Icons shall be:

Simple

Geometric

High Contrast

Outlined or Solid

Consistent Stroke Width

Symmetrical where practical

Icons shall not imitate consumer application icon sets.
