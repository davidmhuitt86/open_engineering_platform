SECTION 8 — STATUS BAR

PRIMARY CHARACTERISTICS
-----------------------
• Short vertical height
• Minimal visual footprint
• Information dense
• Non-distracting
• Highly customizable
• Studio-aware
• Workspace-aware
• Persistent across OEP
• Same component architecture everywhere


CUSTOMIZATION
-------------
Users can:

• Show / hide individual status items
• Reorder items
• Resize items where appropriate
• Choose compact or expanded presentation
• Configure item-specific behavior
• Create Studio-specific layouts
• Create workspace-specific layouts
• Save layouts
• Restore default layout

IMPORTANT
---------

The default configuration should remain clean.

Customization exposes additional information when the engineer
needs it.
